<h1 align="center">Job Tracker</h1>



<p align="center">

&#x20; A full-stack job application tracking application built with React, Node.js, Express.js, and MongoDB.

</p>



<hr>



<h2>📌 Overview</h2>



<p>

Job Tracker is a full-stack web application designed to help users organize and track their job applications in one place.

Users can add job applications, update their status, edit application details, and manage their application history through a simple React-based interface.

</p>



<h2>✨ Features</h2>



<ul>

&#x20; <li>Add new job applications</li>

&#x20; <li>Track company and job position</li>

&#x20; <li>Track application status</li>

&#x20; <li>Record application dates</li>

&#x20; <li>Add notes for each application</li>

&#x20; <li>Edit existing applications</li>

&#x20; <li>Delete applications</li>

&#x20; <li>View all tracked applications</li>

&#x20; <li>Persistent data storage using MongoDB</li>

&#x20; <li>REST API communication between frontend and backend</li>

</ul>

<h2>📡 REST API</h2>



<p>

The application uses a REST API built with Express.js to communicate between the React frontend and MongoDB database.

</p>



<ul>

&#x20; <li><strong>POST</strong> — Create a new job application</li>

&#x20; <li><strong>GET</strong> — Retrieve job applications</li>

&#x20; <li><strong>PUT</strong> — Update an existing application</li>

&#x20; <li><strong>DELETE</strong> — Remove an application</li>

</ul>
